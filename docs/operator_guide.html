Operator Guide

This guide provides operational guidance for security engineers running EnumScan during authorized security assessments.

1. Quick Start Execution

Run a local scan using a YAML configuration file:

go run ./cmd/enumscan -config configs/example.yaml run my-first-scan

2. Generating Reports

Export scan results into HTML, PDF, JSON, SARIF, or Markdown reports:

# Export HTML Report
go run ./cmd/enumscan -config configs/example.yaml report my-first-scan -format html -out ./reports

# Export SARIF for CI/CD Integration
go run ./cmd/enumscan -config configs/example.yaml report my-first-scan -format sarif -out ./reports

3. Launching Web Operator Dashboard

Start the embedded REST API server and operator dashboard:

go run ./cmd/enumscan -config configs/example.yaml serve -port 8080

Navigate to http://localhost:8080 in your web browser to open the dark-mode dashboard.

4. Maintenance & Backups

Create Database Backup

go run ./cmd/enumscan -config configs/example.yaml backup -out ./backups/snapshot.sqlite

Restore Database

go run ./cmd/enumscan -config configs/example.yaml restore -file ./backups/snapshot.sqlite
