API Reference

EnumScan provides REST, WebSocket, and GraphQL APIs for automation, SIEM integration, and web dashboard control.

Authentication

All API requests (except /api/v1/health) require authentication when an API key is configured. Pass your token using HTTP headers:

X-API-Key: your-secret-token

Or via Bearer token:

Authorization: Bearer your-secret-token

REST Endpoints

1. Health Check

  • URL: GET /api/v1/health
  • Auth: Optional
{
  "status": "ok",
  "timestamp": "2026-08-10T11:00:00Z"
}

2. Assets List

  • URL: GET /api/v1/assets?scan_id={scan_id}
  • Auth: Required
[
  {
    "ScanID": "demo-001",
    "Type": "host",
    "Value": "10.0.0.45",
    "Parent": "10.0.0.0/24",
    "Metadata": "active"
  }
]

3. Findings List

  • URL: GET /api/v1/findings?scan_id={scan_id}
  • Auth: Required
[
  {
    "ScanID": "demo-001",
    "Severity": "high",
    "Confidence": "high",
    "Asset": "10.0.0.45:22",
    "Title": "SSH Version Banner Discovered",
    "CVE": "CVE-2023-0001"
  }
]

WebSocket Stream

  • URL: ws://localhost:8080/api/v1/events/ws
  • Protocol: RFC 6455 WebSocket / Server-Sent Events Fallback
{
  "ScanID": "demo-001",
  "Type": "host.discovered",
  "Target": "10.0.0.45",
  "Module": "discovery"
}

GraphQL API

  • URL: POST /query?scan_id={scan_id}
{
  "query": "query { assets { value type } findings { title severity } }"
}
