Authorized-Use & Compliance Guidance

EnumScan is designed exclusively for authorized security assessments, network inventory, and defensive attack surface auditing.

Mandated Rules of Engagement

  1. Explicit Authorization: Operators MUST obtain written authorization from infrastructure owners before running EnumScan against any target outside local loopback.
  2. Scope Enforcement: Always define explicit scope.allowed blocks in your YAML configuration file to ensure probes do not spill over into third-party hosts or shared cloud tenant systems.
  3. Non-Destructive Enumeration: EnumScan modules perform non-intrusive discovery, fingerprinting, and rule evaluation. Intrusive exploitation or payload execution is strictly prohibited.
  4. Third-Party API Compliance: When using passive intelligence integrations (e.g., Shodan, Censys, VirusTotal), operators must comply with vendor rate limits and terms of service.
  5. Data Protection & Secret Handling: Discovered credentials or sensitive configuration files must be handled according to local data classification policies and encrypted at rest.
