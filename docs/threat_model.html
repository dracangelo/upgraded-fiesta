Threat Matrix

Target Scope Unintended Target Scan Critical Mandatory Guard scope checking on every event dispatch.

Defensive Security Controls

  • Input Sanitization: All untrusted targets, headers, and banners are escaped before HTML template rendering.
  • Audit Logging: All administrative API endpoints generate audit log entries ([AUDIT]) recording requesting IP, HTTP method, path, and duration.
  • Least Privilege: SQLite file permissions are restricted (0600), and process handles run without superuser privileges.
