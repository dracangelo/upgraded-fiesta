Configuration Reference

EnumScan is configured using YAML files located in configs/.

Configuration File Schema (configs/example.yaml)

version: "1.0"

# Target Scope Policy
scope:
  allowed:
    - "127.0.0.1"
    - "10.0.0.0/24"
    - "example.com"
  denied:
    - "10.0.0.1"

# Engine & Concurrency Settings
engine:
  min_workers: 2
  max_workers: 8
  rate_limit_per_second: 10
  timeout_seconds: 30

# Persistence Settings
database:
  driver: "sqlite" # Options: sqlite, postgres
  path: "data/scan.sqlite"
  busy_timeout_ms: 5000

# API & Server Options
api:
  port: 8080
  api_key: "" # Leave empty for localhost development
  tls_cert: ""
  tls_key: ""

Field Descriptions

Setting Type Description
scope.allowed List[String] Authorized IP addresses, CIDR ranges, or subdomains.
scope.denied List[String] Blacklisted targets excluded from all network probes.
engine.max_workers Integer Cap on concurrent worker routines.
database.driver String Storage backend (sqlite or postgres).
database.busy_timeout_ms Integer SQLite lock wait timeout in milliseconds.
